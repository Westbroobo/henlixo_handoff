# Henlixo 独立站知识源

这个目录只保留当前独立站第一版仍有价值的内容源。

它不是网站运行时依赖。React 和 FastAPI 运行时读取的是：

- `backend/data/products.json`
- `backend/data/cases.json`
- `backend/data/site-config.json`
- `backend/data/social.json`

本目录用于后续维护产品页、SEO 文案、详情页结构、SKU 参数和公司介绍口径。

## 保留目录

### `01_商品信息知识库/`

用于产品线、产品定位、技术参数、关键词、认证和客群资料。

适合后续更新：

- 首页产品家族文案
- Catalog 产品分类说明
- SEO 标题和关键词
- 产品参数表

### `02_公司信息知识库/`

用于公司介绍、工厂能力、认证合规、服务能力和贸易条款。

适合后续更新：

- Factory & Compliance 区块
- About / Company Profile 页面
- B2B 询盘信任背书

### `05_企业公共知识库/`

当前只保留三份和独立站直接相关的公共资料：

- `01_品牌统一口径_Henlixo.md`
- `07_关键词与SEO体系.md`
- `08_详情页黄金7屏结构.md`

适合后续更新：

- 品牌英文统一口径
- SEO 结构
- 产品详情页模块设计

### `06_商品信息库_SKU/`

用于 11 个 Henlixo SKU 的详细产品事实。

适合后续更新：

- `backend/data/products.json`
- 产品详情弹窗
- 产品详情页
- SKU 对比表

## 已移除内容

以下目录暂时不进入当前独立站源码：

- 沟通技巧
- 沟通专属知识
- 自动接待调优
- 自动回复
- FAQ 问答库
- 展会、区域市场和深度销售话术资料

这些内容更适合以后做 CRM、自动接待、销售助手或 FAQ 系统时单独恢复。
