## 二、按平台的关键词布局

### 阿里国际站

**产品标题模板**(60-128 字符,英文):
```
[Brand Slot] [Style Adjective] Aluminum Bioclimatic Pergola | Motorized Louvered Roof | Customizable | CE Certified | Hotel/Restaurant/Villa
```

实例(SKU01 标准电动百叶):
```
Henlixo Modern Aluminum Bioclimatic Pergola | Motorized Louvered Roof | Customizable RAL Color | CE | Hotel & Villa Outdoor Patio Cover
```

**产品详情页 H1:**
```
Bioclimatic Aluminum Pergola — Henlixo Engineered Outdoor Living
```

**详情页关键词密度规则:**
- 主关键词("Bioclimatic Pergola" / "Aluminum Pergola"): 每屏出现 ≥1 次
- Tier 1 长尾词("Motorized Louvered"): 每屏出现 ≥1 次  
- Tier 3 场景词("Hotel / Resort / Villa"): 每屏出现 ≥1 次
- 单关键词密度 ≤3%(避免阿里 SEO 降权)

### Google Ads

**关键词分组:**

**Group A — High Intent**
- "buy bioclimatic pergola"
- "aluminum pergola supplier"
- "motorized louvered pergola wholesale"
- "pergola manufacturer China"

**Group B — Project**
- "hotel pergola supplier"
- "restaurant patio cover wholesale"
- "resort pergola project"

**Group C — Comparison(夺占 Renson 等)**
- "Renson pergola alternative"
- "Pratic pergola alternative"
- "European pergola alternative"

**Negative Keywords(必排除):**
- "DIY", "Amazon", "Home Depot", "Costco"(过滤零售)
- "Renson", "Corradi", "Pratic"(避免给竞对引流)
- "free", "cheap"(过滤无效流量)
