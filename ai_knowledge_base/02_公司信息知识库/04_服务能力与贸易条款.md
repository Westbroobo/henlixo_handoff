# Henlixo 服务能力与贸易条款

## 一、服务能力全景

### 售前
- **图纸支持**:客户提供项目尺寸/参考图,Henlixo 出 2D / 3D 渲染方案图(免费,3-5 工作日)
- **方案建议**:根据安装国家、风载/雪载/降雨量,推荐结构等级和配置
- **定制咨询**:尺寸、颜色、配件、结构、包装、Logo 全维定制可询
- **快速报价**:常规品 24 小时内出 PI,定制项目 2-5 工作日内
- **样品政策**:1 套起做样,样品费按标准价的 120%(打样工序量小),客户首张正式订单可全额抵扣

### 售中
- 50% 定金到账后排产
- 排产中每周报进度
- 装柜前发产品图 + 试装视频,客户书面确认后再发柜
- 重要订单可全程视频(铝材切割 → 喷涂 → 试装 → 包装 → 装柜)

### 售后
- 24 个月产品质保
- 10 年涂层质保(凭高成 RZ0-20303F 质保书)
- 易损件(电机、传感器、遥控、密封胶条、滑轮)单独供货,海外客户常备包寄送
- 安装指导:发安装图纸 + 视频 + WhatsApp 一对一在线指导
- 出问题先发图/视频,Henlixo 工程师远程诊断;确认是制造问题免费补件,补件运费一般由 Henlixo 承担(空运到机场或就近港口)

## 二、定制能力清单(直接给客户参考)

| 维度 | 可定制 | 不可定制 |
|------|--------|---------|

| 颜色 | RAL 全色卡 / 木纹转印 / 哑光/亮光 | 双色拼接(技术上可,会增包工序) |

## 三、订单流程(8 步)

```
1. 客户提供项目尺寸 / 参考图 / 应用场景 / 国家
   ↓
2. Henlixo 推荐型号 + 方案图 + Quotation(PI)
   ↓
3. 客户确认颜色、配件、Logo、包装方案
   ↓
4. 客户支付 50% 定金
   ↓
5. Henlixo 排产(常规 25-30 天,移动阳光房 35 天)
   ↓
6. 装柜前 — Henlixo 发产品照片 + 试装视频
   ↓
7. 客户书面确认 + 支付尾款 50%
   ↓
8. 发柜 + 提单 / 安装文档 / 在线安装指导
```

## 四、贸易条款

### 标准付款条件
| 客户类型 | 标准条款 |
|---------|---------|
| 新客户 / 1-2 套样品订单 | 100% 预付(TT 全款) |
| 标准小批量(3-10 套) | 50% TT 定金 + 50% 见提单复印件 |
| 大批量 / 老客户 | 30% TT 定金 + 70% 见提单复印件 / LC at sight |
| 项目大单 / VIP 老客户 | 议定(可分批 30/40/30) |
| 试单(战略客户) | OA 30 天(经老板审批,不对外承诺) |

### 接受货币
USD / EUR / AUD / GBP / CAD / CNY(对内)

### 接受贸易术语
EXW Foshan / FOB Guangzhou / FOB Shenzhen / CIF / CFR(常用港口都可)
- DDP 仅限战略客户 + 大单(欧美进口税复杂,慎承诺)
- DAP 可做(末端清关由客户处理)

### 不接受
- 货到付款(海运周期长,风险不可控)
- 寄售 / 代销模式
- 第三方付款(需查 KYC,避免反洗钱风险)
- 部分高风险国家 LC(不出非洲冷门国家 LC)

## 七、OEM / ODM 能力

### OEM(贴牌)
- 客户提供 Logo / 品牌 → Henlixo 印在遥控器、铭牌、包装、说明书
- 起订量:首单 10 套起做(铭牌制作有最小批量)
- 收费:无额外费用(融入标准订单)
- 周期:不影响标准交期

### ODM(原始设计)
- 客户提供概念图 / 参考产品 / 功能要求 → Henlixo 出结构图 + 报价
- 起订量:首单 20 套起做(开模摊销)
- 模具费:视复杂度,USD 500-5,000(订单达量后可退)
- 周期:打样 30-45 天,确认后量产 30 天
