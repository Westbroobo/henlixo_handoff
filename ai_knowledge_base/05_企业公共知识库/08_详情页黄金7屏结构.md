# 详情页黄金 7 屏结构 · Henlixo

> 这一份是 Henlixo 阿里店铺详情页 / 独立站产品页 / 产品手册 PDF 的**统一布局规范**。融合 Renson / Pratic / Corradi / aluno / greenawn 的 5-7 屏最佳实践。

---

## 总原则

- **每屏 1 个核心信息 + 1 个证据 + 1 个 CTA 动线**
- **第 1-3 屏决定 80% 的转化** — 重火力前置
- **图片优先于文字** — 文字 ≤ 30% 屏占比
- **同语种、同色调、同字体、同水印** — 全店 12 个 SKU 视觉统一
- **详情页 ≠ 产品说明书** — 详情页要"卖",说明书 PDF 提供下载

---

## 7 屏布局总览

```
[屏 1] HERO Banner          → 一句话定位 + 主图 + 主 CTA
[屏 2] TRUST 信任墙          → CE / 10 年涂层 / 30+ 国 / 项目案例
[屏 3] PRODUCT MATRIX       → 三档产品(Value / Standard / Project)
[屏 4] DEEP FEATURE         → 主品的 6 大核心卖点
[屏 5] PROJECT GALLERY      → 真实项目案例图(去标识)
[屏 6] SPECS & CUSTOMIZATION → 参数 + 颜色 + 配件
[屏 7] CTA & CONTACT        → 询盘表单 + 联系方式
```

## 阿里详情页 vs 独立站差异

### 阿里详情页特殊要求

- ⚠ 阿里限制图片总大小:每张 ≤300 KB,整页 ≤10 MB
- ⚠ 单图最大尺寸:750×750 px(主图)/ 750×1500 px(详情)
- ⚠ 不能出现外站链接 / 电话 / 邮箱(违规)
- ⚠ "Inquiry" 必须用阿里平台的"Send Inquiry"按钮
- ⚠ 推荐:文字图片化(避免阿里翻译插件错乱破坏排版)

### 独立站特殊要求

- ✅ 高清大图无限制(WebP 格式优化)
- ✅ 视频可嵌入(YouTube + 自托管)
- ✅ 询盘表单可定制(收集更多字段)
- ✅ 可加追踪像素(GA4 + Meta + LinkedIn)
- ✅ 必须 SSL + 隐私政策 + Cookie Banner(GDPR / CCPA)
