# T5 / T6 与质保升级口径 · 面向高端美国/澳洲买家

> 美国 / 澳洲市场的高端 DIY 渠道(theluxurypergola.com、Greenawn 北美等)正在教育买家:"T5 = budget supplier",T6 才是高端。本文档统一 Henlixo 应对策略。

---

## 一、T5 vs T6 真实差异(数据)

| 项目 | 6063-T5 | 6063-T6 |
|------|---------|---------|
| Yield Strength | ~21,000 psi (~145 MPa) | ~35,000 psi (~241 MPa) |
| 牌号差异 | ~120 MPa | ~180 MPa |
| 热处理 | 挤压后人工时效 | 挤压 + 固溶淬火 + 时效 |
| 强度比 | 100%(基准) | +35-40% |
| 成本 | 100% | +15-25% |
| 适用 | 住宅、轻商用、≤5m 跨 | 重型、商业、>5m 跨、强风/雪载 |

> 重要:6063-T5 不是"垃圾铝合金",而是住宅项目的合理选择;T6 是商业 + 极端环境的合理升级。

## 二、Henlixo 的实际情况

- **标准款 / 中型款 / 翻板款 / 尖顶 / R 雨棚 / 阳光房 / 护栏 / 防风帘** 均为 **6063-T5**(供应商富贵花/亨力塑标配)
- **重型款(HL-PG-LV-HD / Henlixo Atlas™)** 默认 T5,**可升级 T6**(项目订单选配,+15-25% 主体成本)

### 场景 2 · 客户说 "其它供应商报的 T6 跟你 T5 同价"

```
EN: That's worth verifying carefully. A few questions to ask the other 
supplier:

1. Can they provide a Mill Test Report (MTR) from their aluminum source 
   showing T6 temper specifically? T6 requires solution heat treatment + 
   aging, which is a different production process than T5.
2. What's the wall thickness? Some suppliers compensate "T6 at T5 price" 
   by reducing wall thickness from 2.0mm to 1.5mm — same strength but 
   thinner.
3. Is the T6 spec for the full structure (frame + posts + beams), or just 
   one component? Some suppliers quote "T6 louver blades" while frame 
   remains T5.

If the other supplier provides verifiable T6 MTR at the same price, that's 
worth considering — but it's rare. Often the "T6" claim is marketing without 
documentation.

Henlixo's pricing is transparent: T5 standard, T6 upgrade at +15-25% 
aluminum cost, with MTR provided.

CN: 值得仔细核对。问对方:
1) 能提供铝材厂 MTR 显示 T6 温度处理证明吗?T6 需固溶 + 时效, 
   工艺与 T5 不同
2) 壁厚多少?有些供应商"T6 同 T5 价"靠减壁厚(2.0mm 减到 1.5mm)补差
3) T6 是整结构(框 + 立柱 + 横梁)还是单部件(只百叶 T6 框还是 T5)?
对方若能给可验 T6 MTR + 同价,值得考虑(罕见);通常是无文件营销说法。
Henlixo 价格透明:T5 标配,T6 升级 +15-25% 铝成本,附 MTR。
```
